## Portfolio Features

* **Interactive 3D Workspace:** A 3D character workstation rendered with Three.js and React Three Fiber, featuring dynamic camera angles and lighting.
* **Modern Frontend:** Built with React 18 and TypeScript for strong typing and performance.
* **Scroll-Driven Motion:** GSAP timelines and ScrollTrigger effects orchestrate section reveals, text animations, and camera transitions.
* **Smooth Inertia Scrolling:** Integrated Lenis smooth scrolling for fluid navigation across desktop viewports.
* **Project Showcase:** Pinned horizontal project scroller on desktop with a dedicated `/myworks` gallery.
* **Accessible Resume Link:** Dedicated Resume action opening the personal PDF (`/Saransh_Singh_Resume.pdf`) directly in a new browser tab.
* **Floating Social Rail:** Magnetic floating navigation providing quick access to GitHub, LinkedIn, LeetCode, and email.
* **Responsive Layout:** Adaptive design ensuring performant fallbacks and touch-friendly layouts on mobile and tablet devices.

## Local Development

### Prerequisites
* [Node.js](https://nodejs.org/) (v18 or higher recommended)
* [npm](https://www.npmjs.com/)

### Installation
Clone the repository and install dependencies:

```bash
npm install
```

### Development Server
Run the local development server:

```bash
npm run dev
```

Visit the local server address displayed in the terminal (typically `http://localhost:5173/`).

### Production Build
Type-check with TypeScript and build optimized production assets:

```bash
npm run build
```

### Preview Production Build
Preview the generated production build locally:

```bash
npm run preview
```

### Linting
Run ESLint to check for code issues:

```bash
npm run lint
```
